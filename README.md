# Sakura World / 山水中国

同一套无限区块引擎，两个独立的生成主题。构建仍输出单个 `index.html`。

```sh
python3 build.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`，通过「世界 · World」切换；中式直达链接为 `http://127.0.0.1:8765/?theme=shanshui&seed=sakura`。`q=high` / `q=lite` 控制画质。Three.js 0.171.0 使用 importmap 加载。

拖动环顾、WASD 移动、E/空格上升、Q 下降。点击动物/鸟/鱼/火车，或使用「跟随」菜单绑定第一视角，Esc 退出。传送菜单可选择各群落和建筑，切换主题和重新生成种子时保留画质。

## 世界规则与资产

| 群落 | 地形、资产与生态 |
| --- | --- |
| 黄山峰林 | 多尺度花岗岩脊与峰针、悬崖松、山亭、古院；高处可见流动体积云海 |
| 云岭梯田 | 等高台阶、水田、稻穗、乡间院落、水牛与仙鹤 |
| 九寨彩湖 | 切入山麓的湖盆、青绿浅水与深潭、柳树、湖心亭、石桥、鱼与仙鹤 |
| 长安灯市 | 轴线院落、飞檐、斗拱、红柱、坊墙、城门、牌楼与灯笼；薄暮/月夜释放孔明灯 |
| 荷塘鹤汀 | 荷叶、荷花、芦苇、垂柳、仙鹤及水牛；早晚贴水雾 |
| 江南竹海与桃源 | 分级竹簇、桃花树和乡间院落；植物间薄雾、花瓣与风动 |
| 樱之世界 | 保留原有神社、鸟居、山寺、城下町、樱花、棚田、铁路等规则 |

城市、结构台基和铁路排除动物刷新；狐狸和鹿检查整个脚印与行走路径，禁止越水或进入水田。中式水牛可在干地/水田岸埂活动，不进入深水。

`world.manifest.json` 是构建和测试共同使用的模块顺序。`10_gen_core` 保留通用噪声、采样和铁路；`10_gen_sakura`、`10_gen_shanshui` 分离主题规则；`10_gen_profiles` 注册群落、生态、传送点、水色和雾参数。`11_gen_*` 管理建筑与植物，`12_gen_lod` 共享所有精度的真实资产位置。渲染侧的水体、植物风动、动物模板、局部雾、孔明灯与第一视角控制分别位于独立模块。

远景保留主树、建筑、车站的同源布局，只减少模型细节和次要植被。隐藏区块实例保持零矩阵；四个子区块就绪后才替换父区块。地形保留完整台阶侧面和区块边界裙边。

水体共用一张有尺寸上限的平面反射目标，高画质/轻量模式调整分辨率、采样和波纹细节；湖水与稻田使用独立配色。局部体积雾与云海复用低分辨率光线步进，孔明灯使用 128/64 实例预算，不创建逐灯点光源。植物和动物共享几何/材质，芦苇、稻穗与柳条的风动固定根部。

## 验证

```sh
node tests/world.cjs
node tests/profiles.cjs
node tests/mist.cjs
```

可选水体逻辑检查：`node tests/water.mjs /absolute/path/to/three.module.js`。该命令显式使用本地 Three ESM 文件，不安装或下载依赖；页面实际 shader 在浏览器中验收。

覆盖无 DOM Worker 生成、三角形绕序、台阶与不同 LOD 接缝、跨主题确定性、中式建筑与资产矩阵、同源远近资产和动物栖息/涉水规则。浏览器验收包括两种画质、反射贴图、世界切换、云海/孔明灯、隐藏实例、近樱花落瓣和移动单位第一视角。

日志保留最近 200 条：`window.__sv.LOG.entries`。访问行为使用 `access`，生成与交互使用 `business`，Worker/运行时异常使用 `error`，按 debug/info/warn/error 分级。
